GenAI Evaluation Framework for NLP Tasks
Classification · Information Extraction · Human-in-the-Loop Annotation · Comparative Evaluation
Key takeaway: simple GenAI baselines are strong, but reliable evaluation needs datasets, metrics and human review.
Amine Smaoui, Ismail Ege Oguz & Robert Pham · TUM
Supervisors: Georg Dietrich & Maximilian Wich · Carl Zeiss AG · 14.07.2026
Dataset, Problem Statement & Main Result
Problem Statement Enterprises are rapidly adopting GenAI to automate classification and extraction, but without standardized evaluation benchmarks, their production reliability remains unverified.
Approach Benchmark GenAI methods on real support tickets (classification) and Few-NERD (entity extraction), then pair them with a human-in-the-loop annotation tool to build trustworthy gold-standard data.
Key finding Zero- and few-shot prompting already perform strongly on classification and extraction — agents add little extra gain, while human-in-the-loop annotation is what builds real trust.

Why It Matters
Decision support: shows when a simple baseline is enough and when extra pipeline complexity is not worth it.
Operational routing: queue accuracy remains the bottleneck, so ticket routing needs better context or labels.
Extraction reliability: all methods are close; structured prompts provide strong results without agent overhead.
Gold data creation: annotation UI turns model suggestions into auditable human-approved evaluation data.
