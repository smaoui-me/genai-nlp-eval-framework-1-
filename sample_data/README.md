# Public sample data

All files in this directory are compact, public demonstration inputs. They may
be copied, modified, and used without company data.

- `tickets.csv` supports the annotation-product walkthrough.
- `classification/embedding_demo/` contains disjoint reference, development,
  held-out, and unlabeled ticket splits.
- `extraction/fewnerd_few_shot_examples.csv` provides three compact public
  demonstrations for both Few-NERD few-shot methods.

See [the complete test guide](../docs/TESTING.md) for executable Docker
commands and expected outputs.
